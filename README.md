# 《集成工艺化学》交互式教学仿真实验平台 (JC00158)

依据**深圳技术大学 · 集成电路与光电芯片学院**《集成工艺化学》（*Chemistry for Integrated Process Technology*，课程编号 `JC00158`）课程教学大纲开发的纯前端交互式教学与实验仿真网页平台。

## ✨ 平台核心特性

1. **全大纲无死角覆盖（7大章节模块 · 共26个交互式定量仿真案例）**：
   - **第一章：化学反应基本规律**（1.1 质量守恒/第一定律/盖斯定律与CVD反应热、1.2 熵与吉布斯自由能 $\Delta G-T$ 自发性判据、1.3 硅外延可逆化学平衡与勒夏特列原理、1.4 反应速率/活化能垒与阿伦尼乌斯方程）
   - **第二章：溶液与离子平衡**（2.1 五种溶液浓度与电子化学品换算、2.2 稀溶液四大依数性与超纯水反渗透 RO、2.3 酸碱质子理论与 BOE 缓冲氧化物刻蚀液机理、2.4 难溶电解质 $K_{sp}$ 沉淀平衡与含氟废水除氟、2.5 配位化合物与大马士革铜互连络合竞争）
   - **第三章：金属元素与金属材料**（3.1 黑色/有色金属分类与酸碱钝化腐蚀实验台、3.2 钛及化合物 $\text{Ti}/\text{TiN}/\text{TiO}_2$ 与17种稀土元素通性及光电/高 $k$ 应用、3.3 置换/间隙固溶体与金属间化合物/形状记忆合金/共晶焊料）
   - **第四章：非金属元素与无机非金属材料**（4.1 非金属单质与硅基 $\text{HF}/\text{KOH}/\text{HNA}/\text{RIE}$ 刻蚀选择比仿真、4.2 固体能带理论与 N/P 型掺杂费米能级载流子仿真、4.3 激光受激辐射谐振腔/石英光纤全反射 NA/超导临界温度 $T_c$ 磁悬浮）
   - **第五章：集成电路专用材料**（5.1 11N电子级硅提纯/CZ直拉单晶/晶体缺陷/SOI与应变硅、5.2 二代/三代化合物半导体 $\text{GaAs}/\text{GaN}/\text{SiC}$ 与量子阱/量子点尺寸发光仿真、5.3 CMP化学机械抛光液协同平坦化与环氧塑封料热膨胀匹配）
   - **第六章：光掩模和光刻胶材料**（6.1 436nm→13.5nm 光谱演进/瑞利分辨率与焦深/DUV透射版 vs EUV反射式 Mo/Si 掩模、6.2 光刻九大核心步骤全流程及 HMDS/PEB 故障诊断、6.3 正性 DNQ/CAR 光刻胶 vs 负性交联胶机理对比度曲线与 TMAH/PGMEA 安全规范）
   - **课内实践模块（5项必做实验虚拟实训）**：
     - 实验一：实验室安全教育、玻璃器皿洗涤、万分之一天平配制 `200 mL 0.1 mol/L NaCl`（含定容俯视/平视/仰视误差分析）及移液管测密度
     - 实验二：氯化钠的提纯（自主设计 $\text{BaCl}_2 / \text{NaOH} / \text{Na}_2\text{CO}_3 / \text{抽滤} / \text{HCl}$ 顺序、实时杂质离子追踪与产率计算）
     - 实验三：溶液配制及酸碱滴定（碱式滴定管半滴精控、酚酞/甲基橙变色渲染、弯月面 `0.01 mL` 估读与 pH 突跃曲线同步绘制）
     - 实验四：正性光刻胶图形化及光刻工艺流程（匀胶机 RPM、数显加热台、紫外曝光机剂量与金相显微镜截面评估）
     - 实验五：负性光刻胶图形化、同掩模正负胶双视场显微镜测微标尺对比及大纲百分制实验考核评分（20%+20%+40%+15%+5%）

2. **双模式章节下拉菜单选择**：
   - 顶部提供**按章节分组的悬浮/点击下拉菜单栏**，直观查看各章完成进度与全部子案例；
   - 同步配备**级联下拉选择框（章节 `<select>` ▸ 仿真案例 `<select>`）**及 URL `#hash` 锚点路由，方便课堂投影与链接直达分享。

3. **零外部依赖 · 原生静态架构**：
   - 不依赖任何易受网络限制的外部 CDN，双击 `index.html` 即可离线运行，直接推送至 GitHub 即可部署在 **GitHub Pages**。

## 🚀 发布到 GitHub Pages 步骤指南

### 方法一：分支直接部署（最简单，推荐）
1. 在 GitHub 上新建一个公开仓库（例如 `ic-process-chemistry-lab`）。
2. 在本文件夹打开终端执行：
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 集成工艺化学交互式教学仿真实验平台"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/ic-process-chemistry-lab.git
   git push -u origin main
   ```
3. 进入 GitHub 仓库页面 → 点击顶部 **Settings** → 左侧菜单点击 **Pages**。
4. 在 **Build and deployment -> Source** 下选择 **Deploy from a branch**，Branch 选择 `main` 与 `/(root)`，点击 **Save**。
5. 等待约 30–60 秒后，即可通过 `https://<你的用户名>.github.io/ic-process-chemistry-lab/` 在线访问！

### 方法二：GitHub Actions 自动部署
本项目已内置 [`.github/workflows/deploy-pages.yml`](./.github/workflows/deploy-pages.yml) 和 [`.nojekyll`](./.nojekyll)，在仓库 **Settings → Pages → Source** 中直接选择 **GitHub Actions** 亦可在每次 `git push` 时自动完成构建与发布。
